description=Lists the species found in a naturalist observation layer without duplicates, grouping on the TAXREF CD NOM identifier rather than on the name as it was typed.
about=French naturalist databases are filled in by several people over several years, and the same species ends up written in several ways: "Abies alba" on one row, "Abies alba Mill., 1768" on the next.
    Grouping by name counts those as two species. This plugin groups on the CD NOM — the stable taxon identifier of the French TAXREF reference — so they count as one. Measured on a real field database: birds go from 457 rows to 287 species, bats from 108 to 35.
    From a loaded vector layer it produces two tables. The first, Species, holds one row per species: scientific name, vernacular name, CD NOM, number of observations, and any extra columns you choose, such as protection statuses. It can be restricted to one biological group when the layer carries such a field.
    The second, To check, records every judgement call and every discarded row — a mistyped CD NOM attached to the majority code, a vernacular name that diverges on a few rows, a row with no scientific name at all. It is the list of corrections to carry back into the database, not a technical log.
    Incomplete determinations such as "Plecotus sp." or "Myotis blythii/Myotis myotis" are not treated as duplicates: they are kept in a column of their own and are not counted as species.
    Fields are detected automatically; the drop-down menus are only there to correct a detection. The interface is in French, as the plugin targets French naturalist data.
